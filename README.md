# Mesa · Cocina de casa

Aplicación escolar de restaurante en Flutter. Incluye menú por categorías, pedido con cantidades y confirmación para recoger. Los precios son de demostración y no se realizan cobros.

## Ejecutar

```powershell
flutter pub get
flutter run -d emulator-5554
```

## Validar

```powershell
flutter analyze
flutter test
flutter build apk --debug
```
